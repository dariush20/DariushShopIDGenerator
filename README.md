# Dariush Shop ID Generator
Offline Android app (Kotlin + Jetpack Compose + Room) that generates unique 10-digit ad IDs.

## Build option A: Android Studio
File > Open this folder, wait for Gradle sync, then Build > Build APK(s)
(or run: gradle :app:assembleRelease). APK: app/build/outputs/apk/release/

## Build option B: GitHub Actions (no install needed)
Push this folder to a GitHub repo > Actions > "Build APK" > Run workflow > download artifact.
